# Tanuj Dhull — Portfolio

A Next.js portfolio highlighting my work in AI, data science, software, education, and hands-on learning.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Create a production build with `npm run build` and run it with `npm start`.

## Customize

- Update school and learning entries in `data/education.js`.
- Replace project content in `app/page.tsx`.
- Add assets under `public/images/` and point to them from the data or page.

The scroll-linked 3D motion respects the operating system's reduced-motion preference and can be paused in the project section.
